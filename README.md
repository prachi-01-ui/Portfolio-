## ✨ About

This repository contains my personal portfolio website, designed to present
my work, technical interests, achievements, and experience in a clean,
interactive, and visually engaging way.

The website focuses on a warm editorial-inspired visual style with subtle
animations, responsive layouts, interactive sections, and smooth scrolling
to create a more engaging experience than a traditional resume.

---

## 🚀 Highlights

- ✦ Interactive hero section with animated text
- ✦ Responsive design for desktop, tablet, and mobile
- ✦ Animated scroll-based section reveals
- ✦ Interactive project filtering
- ✦ Animated skill bars
- ✦ Overlapping / sticky skill cards
- ✦ Interactive project showcase
